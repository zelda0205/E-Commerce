Zelda is an e-commerce web application designed to connect independent artisans with customers looking for unique, handcrafted crochet items. 
The platform provides a seamless shopping experience for buyers while giving craft sellers and administrators the tools they need to manage 
products, orders, and platform analytics.

Tech Stack
Backend: ASP.NET Core MVC (.NET)
Language: C#
Database: Microsoft SQL Server
Frontend: Razor Views, HTML5, CSS3, JavaScript

Key Features
Product Catalog: Browse and filter handcrafted crochet products with detailed descriptions, pricing, and high-quality images.
Shopping Cart & PayPal Checkout: Multi-item cart management featuring secure online payments integrated with PayPal alongside standard checkout 
processing.
Seller Management: Tools tailored for artisans to list, update, and manage their handcrafted inventory.
Admin Dashboard: Centralized management hub equipped with real-time platform statistics and full administrative control over users, orders, and catalog moderation.
User Authentication & Authorization: Role-based access control with secure authentication.
